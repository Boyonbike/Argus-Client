# Fast Use Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Player `FastUse` module that reproduces Meteor's per-hand 0-tick item-use cooldown and Comet's just-placed container guard.

**Architecture:** A new `FastUseModule` owns Meteor-style selection settings and delegates container protection to a pure `ContainerUseGuard`. A MixinExtras injection at `Minecraft.startUseItem` writes the per-hand cooldown; Argus's existing `BlockStateChangeEvent` and `MultiPlayerGameModeUseItemOnEvent` wire the guard without adding new mixins beyond the cooldown hook.

**Tech Stack:** Java 21, Fabric Loader 0.19.5, Minecraft 1.21.11 with official Mojang mappings, Mixin/MixinExtras, JUnit 5.

**Spec:** `docs/superpowers/specs/2026-11-10-fast-use-design.md`

## Global Constraints

- Work only inside `1.21.11/`; do not touch other version trees.
- Java 21 and the existing official Mojang mappings; add no dependencies.
- New module name is exactly `FastUse`, category `PLAYER`.
- Setting config names are exactly `Mode`, `Items`, `Blocks`, `Cooldown`, `PreventContainerOpen`.
- Defaults: `Mode = All`, `Cooldown = 0`, `Blocks = false`, `PreventContainerOpen = true`.
- Do not modify `FastPlaceModule` behaviour or defaults.
- No packet-rate, timer, or rotation spoofing; the only writes are `rightClickDelay` and cancelling `MultiPlayerGameModeUseItemOnEvent`.
- The mixin injection must declare `require = 1` (the mixin config's `defaultRequire` is 0).
- Run all tests from `1.21.11/` with `./gradlew`.

## Review Focus

- A container placed while Use is held must not open on the next interaction: `ContainerUseGuardTest.blocksAContainerPlacedDuringTheCurrentHold`.
- Releasing Use must clear the guard so the next click opens the container: `ContainerUseGuardTest.releaseClearsRememberedPlacements`.
- Sneak-right-click with an item in hand must still place against a just-placed container, while an empty-handed sneak must stay guarded: `sneakWithAnItemBypassesTheGuard` and `sneakWithEmptyHandsIsStillGuarded`.
- `Some` mode with nothing selected must leave the vanilla four-tick cooldown: `FastUseModuleTest.emptySelectionLeavesVanillaCooldown`.
- `All` mode must speed both block and non-block items: `FastUseModuleTest.allModeAppliesTheConfiguredCooldownToEveryItem`.

```java
package dev.argus.mixin;

import com.llamalad7.mixinextras.sugar.Local;
import dev.argus.client.ClientContext;
import dev.argus.client.modules.player.FastUseModule;
import net.minecraft.client.Minecraft;
import net.minecraft.world.item.ItemStack;
import org.spongepowered.asm.mixin.Mixin;
import org.spongepowered.asm.mixin.Shadow;
import org.spongepowered.asm.mixin.injection.At;
import org.spongepowered.asm.mixin.injection.Inject;
import org.spongepowered.asm.mixin.injection.callback.CallbackInfo;

@Mixin(Minecraft.class)
public abstract class MinecraftFastUseMixin {
    @Shadow private int rightClickDelay;

    @Inject(
        method = "startUseItem",
        at = @At(value = "INVOKE",
            target = "Lnet/minecraft/world/item/ItemStack;isItemEnabled(Lnet/minecraft/world/flag/FeatureFlagSet;)Z"),
        require = 1
    )
    private void argusclient$applyFastUseCooldown(CallbackInfo ci, @Local(ordinal = 0) ItemStack heldItem) {
        FastUseModule fastUse = ClientContext.getModule(FastUseModule.class);
        if (fastUse != null && fastUse.isToggled() && fastUse.appliesTo(heldItem)) {
            this.rightClickDelay = fastUse.cooldownFor(heldItem);
        }
    }
}
```

Append `"MinecraftFastUseMixin"` to the `mixins` array in `argusclient.mixins.json`. The `require = 1` is required: the config's `defaultRequire` is 0, so without it a future mapping drift would silently disable the hook.

```java
@Override public void onEnable() { resetGuard(); }
@Override public void onDisable() { resetGuard(); }

private void resetGuard() {
    this.containerGuard.clear();
    this.guardedWorld = ClientAccess.argusclientMinecraft.level;
}
```

Add event handlers:

```java
@EventHandler
private void onPreTick(LocalPlayerPreTickEvent event) {
    Minecraft mc = ClientAccess.argusclientMinecraft;
    if (this.guardedWorld != mc.level) resetGuard();
    if (!this.preventContainerOpenSetting.getValue()) {
        this.containerGuard.clear();
        return;
    }
    if (mc.player != null) this.containerGuard.update(mc.options.keyUse.isDown());
}

@EventHandler
private void onBlockStateChange(BlockStateChangeEvent event) {
    if (!this.preventContainerOpenSetting.getValue()) return;
    Minecraft mc = ClientAccess.argusclientMinecraft;
    if (mc.player == null || mc.level == null || !mc.options.keyUse.isDown()) return;
    boolean container = isContainer(event.getNewState(),
        event.getNewState().getMenuProvider(mc.level, event.getPos()) != null);
    double distanceSq = event.getPos().distToCenterSqr(
        mc.player.getX(), mc.player.getY(), mc.player.getZ());
    if (container && distanceSq <= 64.0) {
        this.containerGuard.placed(event.getPos(), true);
    }
}

@EventHandler
private void onUseItemOn(MultiPlayerGameModeUseItemOnEvent event) {
    if (!this.preventContainerOpenSetting.getValue()) return;
    Minecraft mc = ClientAccess.argusclientMinecraft;
    if (mc.player == null || mc.level == null) return;
    this.containerGuard.update(mc.options.keyUse.isDown());
    BlockPos pos = event.getHitResult().getBlockPos();
    BlockState state = mc.level.getBlockState(pos);
    boolean container = isContainer(state, state.getMenuProvider(mc.level, pos) != null);
    boolean hasHeldItem = !mc.player.getMainHandItem().isEmpty()
        || !mc.player.getOffhandItem().isEmpty();
    if (this.containerGuard.shouldBlock(pos, container,
        mc.player.isSecondaryUseActive(), hasHeldItem)) {
        event.cancel();
    }
}

@EventHandler
private void onDisconnect(MinecraftDisconnectEvent event) {
    resetGuard();
}
```

The module's event handlers are only subscribed while the module is enabled, so `preventContainerOpen = false` still leaves the speed hook working.
